# Securing Electronic Health Records with Real-Time Threat Detection (Wazuh SIEM)
Type: Final-year project
Organisation: Asia Pacific University, completed Aug 2025
Skills: Wazuh SIEM, Linux, SQL injection, DVWA, MITRE ATT&CK, log analysis, threat detection, project management

- Built a VM-based Linux lab with Wazuh SIEM collecting logs and authentication events from simulated healthcare systems.
- Simulated SQL injection attacks against DVWA and wrote custom Wazuh detection rules mapped to MITRE ATT&CK; detections alerted on the dashboard and triggered a timeout as mitigation.
- This was a solo project: I designed, built and tested the whole lab and the detection rules myself.
